# AI Sales Dashboard 📊

An interactive sales analytics dashboard built using Python, Streamlit, Pandas, Plotly, and Machine Learning.

## 📌 About the Project

The **AI Sales Dashboard** is designed to analyze sales data and present important business information in a simple and visual way.

Instead of manually checking large amounts of sales data, users can use the dashboard to quickly understand sales performance, revenue, orders, product performance, and sales trends.

## 🎯 Objectives

* Analyze sales data efficiently
* Display important sales metrics
* Visualize sales trends using interactive charts
* Identify useful patterns in sales data
* Provide data-driven insights for better business decisions

## ✨ Features

* 📊 Interactive sales dashboard
* 💰 Total revenue analysis
* 🛒 Total orders and sales analysis
* 📈 Sales trend visualization
* 🏆 Top-selling product analysis
* 🤖 Machine learning-based analysis/prediction
* 📉 Interactive charts and graphs
* 🔍 Easy-to-understand business insights

## 🛠️ Technologies Used

* **Python** – Main programming language
* **Streamlit** – Dashboard and user interface
* **Pandas** – Data cleaning and analysis
* **NumPy** – Numerical calculations
* **Plotly** – Interactive charts and visualizations
* **Scikit-learn** – Machine learning
* **Joblib** – Saving and loading the trained ML model
* **python-dotenv** – Managing environment variables

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd AI-Sales-Dashboard
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install the required libraries

```bash
pip install -r requirements.txt
```

### 6. Run the Streamlit application

```bash
streamlit run app.py
```

The dashboard will open in your browser.
